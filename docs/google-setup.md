# Google Sheets連携の設定手順

このアプリは、質問への回答からGoogleスプレッドシート（テンプレートのコピー）を新規作成する機能を持っています。
未設定のままでも、質問への回答・下書き保存・A4印刷プレビューはすべて利用できます。
Google連携だけを有効にしたい場合に、この手順に従ってください。

## この方式について（重要）

このアプリには専用のサーバーがありません。ブラウザだけで完結する
「Google Identity Services（GIS）」というGoogleの仕組みを使い、ブラウザから直接
Google Drive API / Google Sheets APIを呼び出します。

- クライアントシークレットは使用しません（ブラウザに置くと漏えいの危険があるため）。
- 取得したアクセストークンはブラウザのメモリ（JavaScriptの変数）にのみ保持し、
  localStorageや外部サーバーには一切送信・保存しません。ページを閉じる・再読み込みすると
  トークンは失われ、再度Googleアカウントでの許可が必要になります。
- 実装上の都合により、OAuthのスコープは `drive`（Googleドライブ全体への読み書き）と
  `spreadsheets` を要求します。これはテンプレート（あなたのドライブ内の既存ファイル）を
  コピーするために必要です。より狭い権限（`drive.file`）にする場合はGoogle Picker APIの
  追加実装が必要です（本バージョンでは未実装）。同意画面には自分のGoogleアカウントのみを
  テストユーザーとして登録するなど、公開範囲を必要最小限にしてください。

## 手順

1. **Google Cloudプロジェクトを作成する**
   https://console.cloud.google.com/ で新しいプロジェクトを作成します（既存のものでも構いません）。

2. **APIを有効にする**
   「APIとサービス」→「ライブラリ」から、次の2つを有効化します。
   - Google Sheets API
   - Google Drive API

3. **OAuth同意画面を設定する**
   「APIとサービス」→「OAuth同意画面」で、User Type を「外部」にし、アプリ名・
   サポートメールなどを入力します。公開ステータスは「テスト」のままで構いません
   （テストユーザーとして自分のGoogleアカウントを追加してください）。

4. **OAuthクライアントIDを作成する**
   「APIとサービス」→「認証情報」→「認証情報を作成」→「OAuthクライアントID」を選び、
   アプリケーションの種類は **「ウェブ アプリケーション」** を選択します。
   「承認済みのJavaScript生成元」に、このアプリを開くURLを追加してください。
   - ローカルで動かす場合の例： `http://localhost:8743`
     （`python3 -m http.server 8743` を使う場合）
   - リダイレクトURIの設定は不要です（トークンクライアント方式のため）。

5. **クライアントIDをアプリに設定する**
   作成されたクライアントID（`xxxxxxxx.apps.googleusercontent.com` の形式）を、
   [`src/google/config.js`](../src/google/config.js) の `GOOGLE_CLIENT_ID` に貼り付けます。

   ```js
   export const GOOGLE_CLIENT_ID = 'ここに発行されたクライアントIDを貼り付け';
   ```

6. **テンプレートへのアクセス権を確認する**
   コピー元のテンプレートは、Googleドライブ内の以下のファイルです（IDは
   [`src/google/config.js`](../src/google/config.js) の `TEMPLATE_SPREADSHEET_ID` で管理）。
   このファイルに、ログインするGoogleアカウントがアクセスできる必要があります
   （自分のドライブ内にあれば通常は問題ありません）。

7. **アプリを再読み込みして「Googleスプレッドシートを作成」を試す**
   最終確認画面のボタンから実行できます。初回はGoogleのアカウント選択・権限許可画面が
   表示されます。

## 動作確認のポイント

- 作成されたファイルが、元のテンプレートと**別のファイルID**であること
- 書類の種類（COMMERCIAL/PROFORMA）と総額が反映されていること
- 数式エラー（`#REF!` 等）が出ていないこと
- 作成したGoogleアカウントでリンクを開けること

これらはアプリ内で自動チェックし、結果を作成完了ダイアログに表示します。

## うまくいかないとき

| 症状 | 確認すること |
|---|---|
| 「Google連携が未設定です」と出る | `GOOGLE_CLIENT_ID` が空のままになっていないか |
| 認証画面が開かない／エラーになる | 承認済みJavaScript生成元にアプリのURLが正しく登録されているか |
| コピーに失敗する（403など） | Google Drive APIが有効化されているか、テンプレートに読み取り権限があるか |
| 書き込みに失敗する | Google Sheets APIが有効化されているか |

失敗しても回答データは失われません。設定を直してから、画面の「再試行する」を押してください。
